## Overview

GLIDE is a Solana token built around a single idea: hold one coin and reach a hand-picked slate of equities, capped at ten, through a connected crypto ecosystem. This repository holds the public site.

## Features

- Live Solana market board with the busiest boosted tokens by daily volume
- A reserved first row for GLIDE that wakes up the moment a contract address is stated
- Ticker, skeleton loading, and motion that steps aside for reduced-motion settings
- Static output, ready to drag onto any static host
